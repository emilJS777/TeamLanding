# TeamLanding

DENeon team portfolio landing page built with Vue 3 and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated static files will be placed in `dist/`.

## Add team members

Edit `src/data/team.js`. Copy Emil's object, change the `id`, profile information, image URL, experience and project list. The cards and profile popup are generated automatically.

## Before publishing

- Replace `hello@deneon.net` if another contact email should be used.
- Add verified team members only after receiving their CV and photo.
- Add LinkedIn URLs where available.
- Review all experience descriptions with each person before publishing.
